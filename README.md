 Conversor de Temperatura em Python

🎯 Objetivo

Este projeto foi desenvolvido como atividade acadêmica para praticar conceitos básicos de programação utilizando Python.

O programa permite realizar conversões entre as escalas Celsius e Fahrenheit.

🛠️ Tecnologia utilizada

- Python

⚙️ Funcionalidades

- Conversão de Celsius para Fahrenheit;
- Conversão de Fahrenheit para Celsius;
- Validação da escala informada;
- Tratamento de entradas inválidas.

📚 Conceitos praticados

- Variáveis;
- Entrada e saída de dados;
- Conversão de tipos;
- Estruturas condicionais;
- Tratamento de exceções com `try` e `except`;
- Formatação de valores.

 💡 Aprendizados

O desenvolvimento deste projeto ajudou a praticar lógica de programação e a compreender como transformar um problema em uma solução utilizando Python.

Também foi possível aprender a tratar erros de entrada e organizar o código de forma mais clara.

🚀 Próximos passos

Como melhoria futura, o projeto poderá receber novas escalas de temperatura e uma interface mais interativa.
